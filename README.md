# Smart Farmer App 🌱

A React-based Smart Farmer Application that helps farmers choose suitable crops based on soil type and season.

## Features

- Select Soil Type
- Select Season
- Get Suitable Crop Recommendation
- Simple and Responsive UI
- Beginner Friendly React Project

## Technologies Used

- React.js
- JavaScript
- CSS
- Vite

## How to Run Project

1. Clone repository

git clone https://github.com/yourusername/FarmerForm.git

2. Install dependencies

npm install

3. Start development server

npm run dev
